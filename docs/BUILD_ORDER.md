# Build order

## Vertical 1

Get RocketRide to run one coding-agent flow against `demo_target/component_a.py`. Feed current test state to Hotdata. Recall prior project context from Cognee and HydraDB. Use Tenki for the candidate remediation. Run the component test and Snyk. Build the exact Action Envelope. Obtain a fresh Gatekeeper verdict. Only an executable verdict may reach the GitHub effect adapter. Persist the Learning Event to Cognee and HydraDB. Capture the successful procedure with Rote.

## Vertical 2

Run the same failure class against `demo_target/component_b.py`. The system should reuse learned context and the Rote procedure, but must query current state again, rerun tests and Snyk, and obtain a fresh Gatekeeper verdict before any effect.

## Evidence

Capture run duration, model/tool invocations where available, test outcome, Snyk result, memory recall evidence, Rote replay evidence, Gatekeeper decision/receipt reference, and resulting GitHub effect.

## Scope rule

Do not add extra UI, extra agent roles, or extra effect surfaces until both verticals work end to end.
